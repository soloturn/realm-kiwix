# realm-kiwix

Yggdrasil/GDD realm for the [Kiwix](https://github.com/kiwix) org.

Currently tracks one component: `kiwix-android`. Auto-detection
(Gradle) covers its build/test commands, so no adapter file is
needed yet.

Use `ws realm https://github.com/soloturn/realm-kiwix.git` to clone
this realm, then `ws realm use realm-kiwix` to select it.
